# Security policy

RepoGuard is a defensive security tool, so we take issues in it seriously.

## Reporting a vulnerability

Please report suspected vulnerabilities privately rather than opening a public
issue:

- Use GitHub's **private vulnerability reporting** (Security → Report a
  vulnerability), or
- email the maintainer listed in the repository's `LICENSE`.

Include a description, affected version/commit, and reproduction steps. We aim
to acknowledge within a few days.

## Scope

RepoGuard only reports and explains weaknesses; it never generates or runs
exploit code, and it must only be used on systems you own or are authorized to
test (see [`DISCLAIMER.md`](DISCLAIMER.md)). Reports about using the tool
against systems without authorization are out of scope.
